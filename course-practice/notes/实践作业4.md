## 原有功能对应到哪些类

下面只写从源码能直接看出来的对应关系。

- 打开应用看到列表：`NotesListActivity`、`NotesListAdapter`、`NotesListItem`、`NoteItemData`。根目录查询排除系统类型，但会在通话记录条数大于 0 时显示通话文件夹。
- 新建和编辑文本：`NoteEditActivity`、`NoteEditText`、`WorkingNote`、`Note`。空内容在保存时可以不生成值得保留的记录，编辑页对空便签设置提醒会提示失败。
- 清单：`NoteEditActivity` 用 `√`（U+221A）和 `□`（U+25A1）作为行前缀，模式存在 `data` 表的 `data1`，常量名是 `Notes.TextNote.MODE`。
- 文件夹：列表菜单创建，长按文件夹可改名或删除。`DataUtils.checkVisibleFolderName` 防止重名。
- 移动：多选后的 `batchMoveToFolder` 只改 `parent_id` 和 `local_modified`，不写 `origin_parent_id`。
- 搜索：`NotesProvider` 对 `snippet` 做 LIKE，并排除回收站和文件夹。编辑页会高亮查询词。
- 分享：编辑菜单使用 `ACTION_SEND`，发送当前正文。
- 导出：列表菜单调用 `BackupUtils.exportToText`，写到外部存储的文本文件，排除回收站。
- 提醒：`DateTimePickerDialog` 选择时间，`AlarmManager` 到点后由 `AlarmReceiver` 打开 `AlarmAlertActivity`。开机由 `AlarmInitReceiver` 重新登记尚未过期的提醒。
- 桌面小部件：`NoteWidgetProvider_2x` 与 `NoteWidgetProvider_4x`。
- 设置与同步账号：`NotesPreferenceActivity`。账号名非空时，旧逻辑把删除改成移入回收站，供同步当作删除标记。
- 通话便签：数据模型在 `Notes.CallNote` 和 `Contact`。列表本身没有拨号界面，记录要由外部用电话号码插入。

## 类注释做到哪一层

每个顶层 Java 文件在类声明前有一句中文类注释，说明这个类负责什么。脚本 `tools/insert_class_comments.py` 只在类前面还没有 JavaDoc 时插入，避免盖住原有许可证头。新类 `NoteTextMetrics`、`TrashPolicy`、`PendingIntentCompat` 的类注释是写代码时直接加上的。

课件还要求方法级注释。若给 433 个方法都写一句“自动释义”，会把未阅读的方法说错。本次的做法是：方法清单全部导出到 `stats/after/java-methods.csv`（文件、声明类型、方法名、参数、行号），但 CSV 不填业务描述。方法、语句块和关键语句三级注释写在作业 5 精读的类里，主要是 `NoteTextMetrics`、`TrashPolicy`，以及 `DataUtils` 的移入回收站和恢复方法。

## 用例图和功能描述

图 1 在 `diagrams/fig-01-usecase.svg`，PNG 为同名文件。白色椭圆是上面列出的原有能力，绿色椭圆是本次实现的字数显示、移入回收站、恢复和清空。同步账号仍画在原有用例里，因为代码还在；图注写明 Google Tasks 的私有接口已经不能当作今天可用的服务。闹钟服务单独作为参与者，因为它由系统在到点或开机时回调，不是用户在列表里点出来的。

软件特性可以收成三句话。它是单机便签：文本、清单、文件夹、提醒、搜索、分享、导出和小部件都在本地 `note.db` 完成。删除在未登录同步时原来是直接删行，回收站 id 虽然存在，界面进不去。同步代码还在，但不能把“能同步”写成当前环境已经验证的功能。

第一次用 SVG 导出 PNG 时，字体写成了机器上没有的 Noto，汉字变成空白方框。改成已安装的文泉驿微米黑后重新导出。因此仓库里同时保留 SVG 源和 PNG。这些图是示意图，不是模拟器截图，图 7 的手机框下方也写了这句话。

## LLM 的作用

助手根据已经读过的类整理功能对照，并生成用例图。类注释的句子是按源码职责写的，不是从方法名机械翻译。没有把握的行为，例如通话便签是否能在本应用里新建，写成“列表没有拨号入口”，而不是编一个通话界面。
