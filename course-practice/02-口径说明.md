# 源码统计口径

统计脚本：`tools/count_sources.py`。结构数字使用 javalang 0.13.0 解析语法树，39 个基线 Java 文件全部解析成功。行数字由脚本自己的扫描器产生，并与 `wc -l` 对过。

## 行

- `wc_newlines`：文件中 `\n` 的个数。文件以换行结尾时等于 GNU `wc -l`。
- `logical_lines`：人看到的行数。若最后一行没有换行，比 `wc_newlines` 多 1。
- 基线里只有 `src/net/micode/notes/ui/DateTimePickerDialog.java` 最后一行没有换行，所以 Java 合计是 `wc -l` = 10001，逻辑行 = 10002。
- `blank_lines`：去掉空白后为空，且不在块注释里的逻辑行。
- `comment_lines`：去掉字符串和字符字面量之后，这一行剩下的非空白内容全部在 `//` 或 `/* */` 里。字符串里的注释符号不算。同一行既有代码又有行尾注释时，整行算代码行。
- `code_lines = logical_lines - blank_lines - comment_lines`。

## 结构

- 包：`package` 声明。基线 8 个，文件数合计 39。
- `types_top_level`：每个 Java 文件直接声明的类型。基线为 39，即一文件一个顶层类型。
- `types_named_including_inner`：包括内部类、内部接口。不含匿名类。基线 65，其中 class 56、interface 8、enum 1。
- `methods_in_named_types`：具名类型里的方法，不含构造方法，也不含匿名类里的方法。基线 433。
- `methods_in_anonymous_classes`：匿名监听器等。基线 34。这些方法如果被漏掉，方法总数会偏小，所以单独列出。
- `constructors`：具名类型的构造方法。基线 38。

脚本不给方法填写业务释义。把没读过的方法写成确定功能，会被当成编造。类的一句职责在源码类注释和 `stats/class-responsibility.csv`。

## 资源

`res/` 下基线 104 个文件：39 个文本资源，65 个二进制图片。文本资源逻辑行 1922。二进制文件里的字节 `0x0A` 不当成代码行，因此汇总表不把 PNG 的换行字节加进代码行。

## 基线与改动后

基线对应改动前的 `master` 提交 `81a6602`，结果在 `stats/baseline/summary.csv`。类注释、两项功能和兼容修改之后的结果在 `stats/after/summary.csv`。两次使用同一脚本，差额来自本次编辑，不是口径变化。

## 已知局限

- javalang 不把匿名类算成具名类型。
- 行扫描器遇到跨行的奇异字符串可能分错，本仓库没有文本块，抽查 `Notes.java` 与 `DataUtils.java` 的行数与分类没有发现整文件偏移。
- “约 10000 行”只在采用 `wc -l` 口径时成立。去掉空行和注释后是 7395 行代码，两个数字不能混用。
