# Windows 11 本机复现步骤

这些步骤写给用户自己的电脑：Windows 11，处理器 i7-14700HX。2026-11-06 的云端实验没有在这台电脑上执行。做完之后，用本机的真实日志替换报告里所有 `/home/ubuntu` 和云端时间。

## 1. 准备

1. 安装 JDK 17 或 21，并确认 `java -version` 是本机输出。
2. 安装 Android Studio，或只装 Android SDK 命令行工具。本机若用 Android Studio，记录版本号。
3. SDK 至少安装：
   - Android SDK Platform 34
   - Build-Tools 34.0.0
   - Platform-Tools
   - Android Emulator
   - 一个 x86_64 系统映像，例如 API 34 的 Google APIs 或 AOSP ATD
4. 克隆或打开的必须是用户自己的 Notes 副本，而不是再去 fork `MiCode/Notes`。

## 2. 取出本次分支

在仓库目录执行（分支名以实际 PR 为准）：

```bat
git fetch origin
git checkout cursor/course-practice-notes-ca85
```

在用户目录创建 `local.properties`，内容只有一行，路径改成自己的 SDK，例如：

```properties
sdk.dir=C:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
```

不要提交这个文件。

## 3. 编译

```bat
gradlew.bat assembleDebug
```

成功时日志里有 `BUILD SUCCESSFUL`。APK 在 `build\outputs\apk\debug\`。仓库里的 `course-practice\dist\notes-debug.apk` 是云端打出来的包，可以先安装对比，但本机报告应附上本机重新编译的包或写明沿用云端包。

云端编译时处理过、本机也会遇到的点：

- `android.nonFinalResIds=false` 已写在 `gradle.properties`，否则 `switch (R.id...)` 编不过。
- `useLibrary "org.apache.http.legacy"` 已写在 `build.gradle`。
- JDK 21 可能提示 Java 8 源级别过时。云端仍然编译成功。若本机失败，把完整错误贴进笔记，不要改成“已成功”。

## 4. 安装到模拟器或手机

```bat
adb install -r build\outputs\apk\debug\Notes-debug.apk
adb shell am start -n net.micode.notes/.ui.NotesListActivity
```

建议把模拟器或手机语言设为简体中文，否则界面用英文字符串。云端若没能完成这一步，以本机截图为准。

手工检查：

1. 新建一条便签，输入“你好”和一行换行后的文字，看标题下是否出现“字 · 行”。
2. 进入清单模式，勾选一项，看是否变成“清单 已完成/总数”。
3. 返回列表，菜单打开“回收站”，此时应为空，且没有新建按钮。
4. 在普通列表删除刚才的便签，确认文案是移入回收站，而不是直接说永久删除。
5. 再到回收站，长按该便签，点“恢复”，它应回到原列表。
6. 再次删除后在回收站里删除或清空，它应消失，且搜索找不到。

把上述每一步的截图放到自己的报告里，并写上本机日期。云端截图如果存在，只能证明云端，不能代替本机。

## 5. 不依赖设备的测试

安装 Python 3 后，在仓库根目录：

```bat
javac -encoding UTF-8 -d %TEMP%\notes-tests src\net\micode\notes\tool\NoteTextMetrics.java src\net\micode\notes\tool\TrashPolicy.java course-practice\jvm-tests\RunToolTests.java
java -cp %TEMP%\notes-tests RunToolTests
python course-practice\jvm-tests\test_trash_trigger.py
python course-practice\tools\count_sources.py src course-practice\stats\after
```

`RunToolTests` 应以进程退出码 0 结束，并打印 `ALL PASSED`。

## 6. 不要做的事

- 不要把结果提交到智慧树，除非使用者自己决定提交。
- 不要向 MiCode 上游发 PR 或评论。
- 不要新建另一个 GitHub 仓库来交作业。
- 不要在报告里写本机处理器已经跑过，除非 `systeminfo` 或任务管理器的记录是你自己截的。
