# 补丁说明

基线提交：`81a66024fe48eaa2206b854430856fe3875ff3ba`（master）。

分支：`cursor/course-practice-notes-ca85`。

## 行为变化

1. 编辑页增加字数和清单进度，不写数据库。类 `NoteTextMetrics`。
2. 未配置同步账号时，删除不再直接 `DELETE`。普通位置改为更新 `parent_id=-3` 且写入 `origin_parent_id`。回收站菜单、恢复、清空为新增界面路径。已在回收站时仍调用原来的 `batchDeleteNotes`。
3. 数据库版本 4 升到 5。升级只重建 `folder_move_notes_on_trash`，使子便签记下原文件夹 id。无新表、无新列。

## 为了能编译和安装而改的兼容项

这些不是 SRS 里的产品需求。

- 增加 Gradle 构建文件。`local.properties` 不入库。
- minSdk 14 改为 21，targetSdk 34，组件补 `android:exported`。
- `PendingIntent` 增加不可变标志。
- 同步通知不再调用已删除的 `setLatestEventInfo`。
- `gradle.properties` 关闭 non-final R 类，否则旧的 switch 不能编译。
- 使用 SDK 自带的 `org.apache.http.legacy`。

## 每个顶层类

增加了一句中文类注释。精读模块另有方法级和关键语句注释。

## 明确没有改的结构

- 没有 `CREATE TABLE note_label` 或 `note_label_map`。这两张表只出现在设计说明书和图 8，标注为拟新增。
- 没有改 `app_name`。
- 没有改搜索 SQL 对回收站的排除。
- 没有向 `MiCode/Notes` 推送。

## 回退

若要回到改动前的删除行为，需要同时恢复 `NotesListActivity`、`NoteEditActivity` 的删除分支、`DataUtils` 的新方法，以及数据库版本和触发器。只恢复 Java、不恢复触发器，文件夹的子便签在版本 5 的库上仍会写下 `origin_parent_id`。
