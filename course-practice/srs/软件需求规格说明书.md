## 1. 引言

### 1.1 目的

说明“便签备忘”相对社区版小米便签要保持的原有能力，以及本次确定交付的两项改进。读者是课程实践的编写和检查，不是应用商店的用户手册。

### 1.2 范围

范围是这份仓库里的 Android 应用。项目名称“便签备忘”只用于课程文档。安装后的显示名仍取自字符串资源：中文“便签”，英文 Notes。不改包名，不新开仓库。

本次交付的行为变更只有两项：编辑时显示字数和清单进度；删除先进入可浏览、可恢复的回收站。标签表只在设计说明书中作为拟新增出现，不属于本需求的交付范围。

## 2. 总体描述

### 2.1 产品前景

使用者在本机记录短文本、清单和提醒。数据在应用私有数据库 `note.db`。原有桌面小部件、搜索、分享和文本导出保留。

### 2.2 用户

主要参与者是使用手机的人。次要参与者是 Android 的 `AlarmManager`：到点或开机时回调应用。Google 账号只与源码中仍存在的同步设置有关，本次不把它写成可用的外部系统。

### 2.3 约束

- 原工程为 Java，界面资源是 Holo 主题时代的布局。
- 为能在当前 SDK 上安装，构建配置把 minSdk 调到 21、targetSdk 调到 34。原清单曾写 minSdk 14。
- 已有数据库版本 4 只有 `note` 和 `data`。回收站不得另起一套未在需求中说明的表来保存被删便签。

### 2.4 假设

假设使用者允许应用使用其声明过的存储、联系人、开机和网络权限。联系人权限只为通话便签显示姓名。本次云端实验没有插入真实联系人，因此通话姓名显示未验证。

## 3. 功能需求

### 3.1 原有功能（分析模型，不展开到每个方法）

下列功能在社区版源码中已经存在。本需求要求改进后仍然保留，除非 3.2 明确写了“取代”。

1. 查看便签和文件夹列表，按类型和修改时间排序。
2. 新建、打开和编辑文本便签。
3. 清单模式：勾选状态保存在正文行的前缀和 `data1` 模式位。
4. 新建、改名、删除文件夹，并把便签移动到文件夹。
5. 按摘要搜索，结果不包含回收站中的便签。
6. 分享当前正文，把全部未在回收站的便签导出为文本。
7. 设置和取消提醒；到点提示；开机后恢复未过期提醒。
8. 2×2 与 4×4 桌面小部件。
9. 设置页保存同步账号和“新建背景是否随机”。
10. 通话便签的数据形态：号码和通话时间存在 `data` 表。列表不提供拨号。

同步：设置页和 `gtask` 包仍在。需求不把“与 Google Tasks 成功同步”列为本次必须通过的验收项，因为该客户端指向的私有接口已停用，且本次没有账号验证。

原删除行为被 3.2 取代：未配置同步账号时直接物理删除、配置后才进入回收站，且界面不能打开回收站。

### 3.2 新增与改进（详细）

#### 需求 R1 编辑字数与清单进度

编辑页在修改时间附近显示统计。

- 字数等于当前文本的 Unicode 码点数。空文本为 0。一个 emoji 计 1。
- 同时给出 UTF-16 单元数只用于实现自测，界面默认不单独展示这一列。
- 行数：空文本为 0；文本中间的空行计入；结尾的一个换行不额外增加一行。
- 若存在以 `√` 或 `□` 开头的行（允许行首空白），界面改为显示“字数 · 清单 已完成/总项”。标记与编辑页保存清单时使用的字符相同。
- 统计不写入数据库，旋转或离开界面后重新根据正文计算。

验收：对“你好”、单个 emoji、`"a\nb"`、`"a\n"`、`"√ 买菜\n□ 写作业\n普通\n"` 的计数与 `RunToolTests` 中的断言一致。界面是否画出该行，另以真机或模拟器截图验收。

#### 需求 R2 回收站

- 系统仍使用已有文件夹 id `-3`，不新建回收站表。
- 使用者在普通列表或编辑页确认删除时，便签或用户文件夹的 `parent_id` 变为 `-3`，并把删除前的父 id 写入已有列 `origin_parent_id`。根、临时、通话、回收站这四个系统文件夹不能被删除。
- 列表提供进入回收站的菜单。回收站中不显示新建按钮。
- 在回收站中选择恢复：父 id 改回 `origin_parent_id`。若该值为 `-3` 或 `-1`，或原用户文件夹已经不存在，则回到根目录 `0`。根目录和通话文件夹作为原位置时保持不变。
- 在回收站中再次删除，或选择清空，才物理删除 `note` 行。原有触发器会删除对应 `data` 行。
- 文件夹移入回收站时，其子便签一并进入回收站，并把原文件夹 id 记入子行的 `origin_parent_id`。这是版本 5 触发器相对版本 4 的行为变化。
- 搜索和文本导出继续排除回收站，此条保持原行为。

验收：`TrashPolicy` 的单元测试，以及内存 SQLite 对触发器的检查。从版本 4 数据库文件实际升级到版本 5，本次未在设备上做，不能勾成已通过。

### 3.3 明确不做

- 不实现标签、置顶、密码锁。
- 不修复或替换 Google Tasks 协议。
- 不改变包名和应用显示名。

## 4. 非功能需求

- 字数统计在本地完成，不联网。
- 移入回收站使用现有 ContentProvider 批量更新，不复制正文到第二套存储。
- 界面文字沿用原有英、简体、繁体资源，新增字符串三种语言都要有。
- 需求语句前后一致：除回收站内的永久删除外，文档中的“删除”都指移入回收站。
